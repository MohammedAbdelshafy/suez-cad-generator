# Coastal Structures Studio Commercialization

## Product
Planning-level port dimensioning and CAD/masterplan generator from design-vessel particulars.

## Buyer
Maritime consultants, developers, port planners, engineering teams, and early-stage feasibility studies.

## Deliverable
Calculated planning dimensions plus exportable DXF/SVG/PNG/JSON masterplan artifacts.

## Commercial boundary
Planning-level only. The existing README correctly excludes construction use and requires qualified engineering verification.

## Packaging
Pilot/feasibility report, custom presets, branded exports, and consulting-assisted design reviews.

## Expansion
Custom standards, project templates, API access, team collaboration, and report automation.
